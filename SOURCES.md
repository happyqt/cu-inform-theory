# Внешние источники

- `tests.py` — файл тестов сгенерирован с помощью OpenAI Codex. Назначение: проверка источников, равномерного кодирования, архиватора и обработки некорректных входов.

- `main.py` (настройка `argparse` и разбор аргументов), `run.sh` (запуск программы и передача аргументов) — заимствованные фрагменты, подготовленные с помощью OpenAI Codex. Спросил у кодекса как это работает, какие должны быть команды и аргументы, какие изменения надо внести в питоновские файлы.
